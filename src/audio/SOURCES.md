# Public WebXR audio

The WAV loops in this folder are original procedural sounds created for Sound Room, reused from this workspace's Unity port. They contain no SATIE evaluation recordings or account-specific content. `books.wav` reuses the original page-turning loop; `strings.wav` is an original synthesized drone generated by scripts/generate-drone.py. The public Pages app uses Web Audio HRTF panning and synthetic convolution reverb, not Attractor or SATIE runtime.
